## tloen/alpaca-lora (Apache-2.0)
Repository: https://github.com/tloen/alpaca-lora - author Eric J. Wang (`tloen`). The repository's `LICENSE` is the Apache License 2.0
and is reproduced unchanged in this repo's `LICENSE`. Studied files: `finetune.py`, `generate.py`, `utils/prompter.py`, `templates/alpaca.json`.

**What is based on it (structure / ideas):**
- The overall LoRA fine-tuning recipe in `finetune.py`: load a base causal LM, wrap it with a PEFT `LoraConfig` (defaults r=8, alpha=16, dropout 0.05), tokenize "### Section" style prompts, train with the Hugging Face `Trainer`, save only the adapter.
- The `### Instruction / ### Input / ### Response` prompt style (this project's template uses `### Email / ### Intent`).
- The idea of keeping the prompt template separate from the training code (`Prompter`).

**Changes (Apache-2.0 section 4(b) statement of changes) - everything below is new code written for this project:**
- Task: 6-way customer-email intent classification instead of general instruction following.
- **Data: a new, original, hand-written dataset** (`data/emails.jsonl`, 120 fictional emails, generated by `data/build_dataset.py`).
  The Alpaca instruction data is **not** used or redistributed (it has its own license, ODC-By 4.0, and is machine-generated), so none of its terms apply here.
- Loss only on the answer tokens (`train_on_inputs=False` by default; alpaca-lora defaults to `True`).
- Modern stack: no `prepare_model_for_int8_training` / bitsandbytes / wandb / `LlamaForCausalLM`-specific code; works with any HF causal LM and current `transformers`/`peft`; small model (Qwen2.5-0.5B-Instruct, Apache-2.0) that fits a free Colab GPU.
- Deterministic stratified train/val/test split with a leakage check.
- Evaluation harness (new): base zero-shot vs tuned, strict and lenient answer parsing, accuracy, macro-F1, per-class metrics, confusion matrix, invalid-answer rate, majority-class baseline.
- Tests, including an offline smoke test of the whole train→save→reload→evaluate path on a tiny random model.
- Colab notebook; documentation.

Not used: `generate.py`, the export scripts, the Dockerfile, Alpaca datasets, the LLaMA weights.

## Base model
`Qwen/Qwen2.5-0.5B-Instruct` (Alibaba Cloud, Apache-2.0) is downloaded from Hugging Face at run time and is not redistributed here.
